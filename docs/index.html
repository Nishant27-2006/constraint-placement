Where does a hard physical constraint belong in a generative model?

Four routes reach the same feasible set. We built a benchmark that varies one thing — the fraction of the state the physics already determines — and measured which route wins. The answer changes sign.

01The question

A generative model of grid scenarios should respect the physical laws its samples are supposed to satisfy. Several routes achieve exact satisfaction, and the literature disagrees about which to use — mostly without comparing them on matched conditions. The routes:

The benchmark varies codimension — the fraction of each hour's state that the constraints fix analytically. The two grid suites are the same 118-bus system and the same measured injections; the only change is whether the model must also emit the 186 line flows that the constraint matrix determines exactly. Finding 1. On the controlled contrast, raising codimension turns train-time projection from statistically indistinguishable from doing nothing into a significant win. On a third suite — a genuinely different data-generating process, EIA-930 accounting identities rather than Kirchhoff on a synthetic network — the same code is significantly worse. The effect is not a constant that a better implementation would move. Anyone reporting a single winner has measured one suite.

One alternative explanation was checked and rejected: channel scale heterogeneity does not account for the pattern. grid-noflow has the widest scale spread (36×) and shows no effect.

03Soft penalties are dominated on both axes

The default in physics-informed generative modelling is to add λ‖Ax−b‖² to the loss and raise λ until violations look acceptable. That trade-off does not exist here.

Finding 2. On grid, three orders of magnitude of λ move the violation from 219 MW to 187 MW — the same order, still operationally unacceptable — while the energy score degrades monotonically to +92%. Every exact route beats the entire penalty family on feasibility and fidelity at once. There is no λ to tune.

04Feasibility is not decision value

Proper scoring rules are the currency of this literature. We also ran the decision: two-stage stochastic unit commitment, commitment frozen on the generated scenarios, scored on the realised day, regret measured against perfect foresight.

Each point is one generator. Filled points are the exactly-feasible routes. The dashed line is least squares.

-0.933corr(cost regret, 90% coverage) — Spearman ρ = -0.62, p = 0.011
+0.315corr(cost regret, energy score) — Spearman ρ = +0.23, p = 0.39, not significant

Finding 3, the one we least expected. Physical feasibility of the scenario set does not reach the scheduling decision at all; calibration carries it. The exactly-feasible train-time routes take the worst regret among neural methods (FM+reduced 66%, FM+DC3 58%, ours 53%) and the best belong to the two most over-dispersed baselines (GaussianCopula 16%, NormFlow-RealNVP 16%). Exactly-feasible ensembles are sharper, the scheduler trusts them, under-commits reserve and pays in load shed.

A study that stopped at the energy score would have reported the opposite conclusion with confidence. Stated with its limit: this stage has 3 seeds, not 10.

05Exactness is free in function evaluations

548 → 20NFE to reach the best score unconstrained FM attains anywhere on the frontier (543.7)
0extra function evaluations for the projector route, against 51 extra projections for inference-time correction on a 50-step solve

Finding 4. Train-time projection reaches 539.5 at NFE 20 (euler) — 27× fewer evaluations for a better score, with the violation at 0.000534 MW against 457 MW. Removing the determined directions from the hypothesis class buys far more than any solver schedule, because the adaptive solver spends its budget integrating directions that are known in closed form.

Efficiency is reported as NFE and analytic FLOPs, which are exactly countable and hardware-independent — not as device joules.

06What we predicted, and got wrong

Every claim was written into a pre-registration with an explicit falsification condition before the sweep ran, so the acceptance criteria could not drift to fit the output. Two conditions fired.

Falsified · C3

We predicted train-time ≤ inference-time ≤ post-hoc on fidelity, universally.

Measured: the ordering holds on grid (-3.39% for train-time against inference-time, t = -9.09) and reverses on measured (+3.38%, t = +5.05). The reversal became the paper's central finding.

Falsified · C5′

We predicted that under an N-1 topology swap, routes working in physical coordinates keep their learned distribution while chart-based routes do not.

Measured: ours 896.4 against FM+reduced 881.8 — indistinguishable — and both beaten by FM+posthoc 651.5. Per the pre-registration the transfer differentiator was dropped from the paper rather than softened.

Negative result · AC manifold

We predicted that per-step retraction would be needed to bound drift on the nonlinear AC power-flow manifold.

Measured: a single retraction after the solve reaches |g|∞ = 0.0077 from 5.1, essentially free in score. Per-step retraction at a budget of 3 Gauss-Newton iterations reaches only 129 — worse than doing nothing — because the in-loop pull-back never converges and injects a biased correction at every step. Reported with the diagnosed cause, not omitted.

A non-neural baseline places second of sixteen on both grid suites. kNN-Historical resamples analogue days: zero parameters, zero function evaluations, exactly feasible by construction. It beats every GAN, VAE and normalising flow on all three suites. The pre-registration committed to putting it in the abstract if it won, so it is in the abstract.

07Reproducing it

No number in the paper, this page or the record is typed by hand: all are generated from the run files. The repository ships the code and the pre-registration; results/ is what running the pipeline creates.

pip install -r requirements.txt
bash scripts/download_data.sh      # public data, no API key
python scripts/build_datasets.py --which all
bash scripts/run_everything.sh     # idempotent, resumable
